Python / Static ethics view

White hat, black hat

A static pair of Python charts showing how the same emissions data can be presented transparently or manipulated through framing, cherry-picking, and axis design.

Back to project home Next: Tableau dashboard
Reading path Compare the framing before you compare the values

Both charts use the same Europe & Central Asia emissions series. What changes is the frame: one keeps the longer window and honest baseline, while the other narrows the period and exaggerates the rebound.

Assignment requirement

Two perspectives on the same data

White hat

Transparent trend

The ethical version shows the full 2014-2021 trend for Europe & Central Asia and starts the y-axis at zero. This makes the chart less visually dramatic, but it allows the viewer to assess the real magnitude of the change more accurately.

Design choice: context before drama.

Black hat

Manipulated rebound

The misleading version keeps only 2019-2021 and crops the y-axis. The COVID-era dip and rebound look like a dramatic emissions spike, even though the longer trend gives a more moderate interpretation.

Design choice: drama before context.

What it teaches

Axes and windows are arguments

A chart is never neutral by default. The chosen time span, baseline, title, and axis limits can change the story even when the underlying data points are not altered.

For this project, transparency is part of the analysis.
